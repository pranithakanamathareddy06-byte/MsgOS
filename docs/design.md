# MsgBus - Publish/Subscribe Message Bus

## Project Description

MsgBus is a simple publish/subscribe message bus implemented
using C programming and Linux IPC mechanisms.

## Main Components

1. Publisher
2. Message Broker
3. Subscriber

## Basic Workflow

Publisher sends a message to the Message Bus.

The Message Bus receives the message and forwards it
to the appropriate Subscriber.

## Platform

Ubuntu Linux

## Programming Language

C
