# MsgBus

MsgBus is a simple Publish/Subscribe message bus implemented
using C programming and Linux system programming concepts.

## Main Components

- Publisher
- Message Broker
- Subscribers

## Linux Concepts Used

- fork()
- pipe()
- FIFO
- read()
- write()
- waitpid()
- signals
- malloc()
- free()
- process IDs
- process groups

## Platform

Ubuntu Linux

## Language

C

## CO Coverage

CO-1: Linux system calls and operating system services

CO-2: Process creation, synchronization and termination

CO-3: IPC using pipes, FIFO and signals

CO-4: Dynamic memory and process memory concepts
